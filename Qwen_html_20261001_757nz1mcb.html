📈 Графиктер

Қолдау: y = x²

Орта: y = 4−x²

Жоғары: y=x, y=2−x²

📘 Қолдау деңгейі: y = x², 0 ≤ x ≤ 1

Қолдау Алгоритм бойынша есептеңіз

y = x², x = 0, x = 1 түзулерімен шектелген фигураның ауданын табыңыз.
💡 Алгоритм: 1) Шектерді жаз → 2) Интеграл құр → 3) Алғашқы функцияны тап → 4) Ньютон–Лейбниц формуласымен есепте.
1Шектерді анықтаңыз 1 балл
2Интеграл астындағы функция 1 балл
3Алғашқы функция 1 балл
4Ньютон–Лейбниц формуласымен есептеңіз 1 балл
5Жауапты негіздеңіз (неге осындай интеграл?) 1 балл
✅ Дұрыс жауап: S = ∫01 x² dx = [x³/3]01 = 1/3 − 0 = 1/3

📗 Орта деңгей: y = 4−x², y = 0, x = 0, x = 2

Орта Фигураның ауданын табыңыз

y = 4 − x², y = 0, x = 0, x = 2 шектерімен берілген фигураның ауданын табыңыз.
1Шектерді анықтаңыз 1 балл
2Жоғарғы функцияны анықтаңыз 1 балл
3Интегралды құрыңыз 1 балл
4Есептеңіз 1 балл
5Жауапты негіздеңіз 1 балл
✅ Дұрыс жауап: S = ∫02 (4−x²) dx = [4x − x³/3]02 = (8 − 8/3) − 0 = 16/3

📕 Жоғары деңгей: y = x және y = 2−x²

Жоғары Қиылысу нүктелерін табыңыз

y = x және y = 2 − x² графиктерімен шектелген фигураның ауданын табыңыз.
💡 Нұсқау: Алдымен қиылысу нүктелерін анықтаңыз: x = 2 − x² → x² + x − 2 = 0 → (x+2)(x−1) = 0 → x = −2 немесе x = 1.
1Қиылысу нүктелерін табыңыз 1 балл
2Шектерді анықтаңыз 1 балл
3Жоғарғы функцияны анықтаңыз 1 балл
4Интегралды құрыңыз және есептеңіз 1 балл
5Жауапты негіздеңіз 1 балл
✅ Дұрыс жауап: x² + x − 2 = 0 → x = −2, x = 1
[−2;1] аралығында 2−x² ≥ x, сондықтан
S = ∫−21 (2 − x² − x) dx = [2x − x³/3 − x²/2]−21 = 9/2

🏆 Жалпы ұпай

Сіздің нәтижеңіз:

0 / 15 балл

📋 Дескрипторлар (әр дұрыс қадам — 1 балл):

  • Шектерді (интегралдау аралығын) дұрыс анықтайды;
  • Жоғарғы және төменгі функцияны ажыратады;
  • Аудан интегралын дұрыс құрады;
  • Есептеуді дұрыс орындайды;
  • Жауабын негіздейді (неге осы формула қолданылғанын түсіндіреді).

Бағалау шкаласы:
